A browser cannot send SMTP. Nothing in a web page can open a socket to port 587, and if it could, the password would be readable by anyone using the page. These settings are held so the server can use them: the API sends the mail, and this screen only decides what it sends and to whom. How to use these. Open the GST Returns Offline Tool, choose Import Files, then import each CSV into its matching section. Dates are formatted DD-MMM-YYYY and place of supply as "29-Karnataka", which is what the tool expects. Column sets differ between versions of the offline tool — check yours against the headings before a live filing.
